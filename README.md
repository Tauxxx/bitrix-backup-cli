# Инструкция по работе с зашифрованными архивами 1С-Битрикс через CLI

Консольная утилита [`bx-backup.php`](./bx-backup.php) предназначена для выборочного просмотра и извлечения файлов (изображений, PHP-скриптов, SQL-дампов базы данных и др.) из многотомных зашифрованных резервных копий 1С-Битрикс (`*.enc.gz`, `*.enc.gz.1`, ..., `*.enc.gz.N`).

Утилита работает полностью в консоли (CLI), не требует веб-сервера и браузера.

---

## 1. Как устроен зашифрованный архив Битрикса

1. **Тома архива**:
   - `*.enc.gz` — первый том архива.
   - `*.enc.gz.1`, `*.enc.gz.2`, ... `*.enc.gz.N` — последующие номерные тома (разбивка обычно по 100 МБ).
2. **Шифрование**:
   - Первый том содержит 512-байтный заголовок с сигнатурой `Bitrix Encrypted File 1.2` и проверочным блоком.
   - Ключ шифрования формируется как `md5(пароль)`.
   - В качестве алгоритма используется потоковый блочный шифр `AES-256-ECB` (в старых версиях — Blowfish `bf-ecb`).
   - Номерные тома (`.1`, `.2`, ...) содержат продолжение непрерывного зашифрованного потока.
3. **Формат данных**:
   - После расшифровки и распаковки `gzip` получается стандартный поток архива `TAR`.
   - Утилита потоково парсит заголовки TAR и распаковывает только выбранные файлы без необходимости предварительно разворачивать весь архив на сотни гигабайт.

---

## 2. Системные требования

* **PHP 8.0+** (CLI).
* Расширения PHP: `openssl`, `zlib` (входят в стандартную поставку PHP / Herd / Homebrew).

Права на запуск:
```bash
chmod +x bx-backup.php
```

---

## 3. Быстрый старт

Если запустить утилиту в папке с архивом без указания файла, она **автоматически найдет** архив в текущем каталоге. Если архив зашифрован, утилита запросит пароль в интерактивном режиме (скрывая ввод символов) либо пароль можно передать аргументом `-p <пароль>`.

### 3.1. Информация об архиве (`info`)
Показывает число томов, общий размер на диске и алгоритм шифрования:
```bash
./bx-backup.php info
```

Пример вывода:
```text
Archive Information:
  First file:         my_site_20261009_022847_full_abcdef.enc.gz
  Volumes detected:   42 part(s)
  Total size on disk: 3.17 GB (3,399,495,168 bytes)
  Encrypted:          Yes (aes-256-ecb)
  Volume chunk size:  100 MB
```

---

### 3.2. Поиск и список файлов (`ls` / `list`)

```bash
# Найти все JPG-изображения с подробностями (размер, дата)
./bx-backup.php ls "*.jpg" -d

# Найти первые 20 файлов в каталоге upload
./bx-backup.php ls "upload/*" --limit=20

# Найти PHP-скрипты
./bx-backup.php ls "*.php"

# Вывести все файлы без ограничения лимита (по умолчанию лимит 50 строк)
./bx-backup.php ls "*.png" --limit=0

# Вывести только «чистые» пути (удобно для конвейера xargs / grep)
./bx-backup.php ls "*.webp" --raw
```

---

### 3.3. Извлечение файлов (`extract` / `x`)

#### Извлечение одного файла
```bash
# С сохранением исходных путей каталогов (в папку ./extracted):
./bx-backup.php extract "upload/iblock/123/banner.jpg" -o ./extracted

# Плоское извлечение (без создания подпапок, положит файл сразу в целевую директорию):
./bx-backup.php extract "upload/iblock/123/banner.jpg" -o ./images --flat
```

#### Извлечение группы файлов по маске
```bash
# Извлечь модуль или раздел сайта:
./bx-backup.php extract "local/components/*" -o ./my_project

# Извлечь все файлы определенного типа из upload:
./bx-backup.php extract "upload/*.png" -o ./restored_png
```

#### Извлечение базы данных (SQL dump)
```bash
./bx-backup.php extract "*.sql" -o ./sql_dumps
```

---

### 3.4. Просмотр файла в терминале без сохранения (`cat` / `view`)

Содержимое файла направляется прямо в `STDOUT`, что позволяет читать файлы или направлять их в `grep`, `less`, `head` и т.д.:

```bash
# Просмотр конфигурации Битрикса:
./bx-backup.php cat "bitrix/.config.php"

# Поиск нужной строки в PHP-скрипте из архива:
./bx-backup.php cat "local/php_interface/init.php" | grep "AddEventHandler"

# Просмотр первых строк дампа базы:
./bx-backup.php cat "bitrix/backup/dump_after_connect.sql"
```

## 4. Справка по флагам и параметрам

| Параметр | Алиас | Описание | Значение по умолчанию |
|---|---|---|---|
| `--archive=<путь>` | `-a` | Путь к первому тому архива (`*.enc.gz` или `*.tar.gz`) | Автоопределение в текущей папке |
| `--password=<пароль>` | `-p` | Пароль расшифровки | Запрашивается интерактивно при наличии шифрования (или переменная `BITRIX_ARCHIVE_PASSWORD`) |
| `--output=<папка>` | `-o` | Папка назначения для извлеченных файлов | `./extracted` |
| `--flat` | `-f` | Не создавать подкаталоги (сохранять файлы сразу в `--output`) | `false` |
| `--overwrite` | `-y` | Перезаписывать существующие файлы при извлечении | `false` |
| `--details` | `-d` | Отображать размер, дату изменения и тип файла в списке | `false` |
| `--limit=<N>` | `-l` | Лимит строк в выводе команды `ls` (0 — без ограничений) | `50` |
| `--raw` | | Выводить только пути к файлам без форматирования | `false` |
| `--help` | `-h` | Показать справку по командам | |
